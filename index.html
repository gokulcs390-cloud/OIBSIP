⚡ Quick Start & Run Instructions

Clone the repository and run any task directly on your machine:

git clone https://github.com/gokulcs390-cloud/OIBSIP.git
cd OIBSIP
pip install -r requirements.txt

# Launch the Interactive Project Hub (Runs all tasks)
python run_all_hub.py

# Or run individual task GUIs:
python Python-Task2-BMICalculator/bmi_calculator_gui.py
python Python-Task3-PasswordGenerator/password_generator_gui.py
python Python-Task4-WeatherApp/weather_app_gui.py
